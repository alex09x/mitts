# Mitts 0.5.1

Cargo parity, each with tests:

- **Cross-compilation** with `--target`: target units in `target/<triple>/`, build
  scripts, build-dependencies and proc macros for the host, `[target.'cfg(..)']`
  dependencies and `CARGO_CFG_*` for the target, executables with the target's suffix
  (`.wasm`, `.exe`). Tested for wasm32-unknown-unknown on Linux, macOS and Windows; a
  wasm32 build on a Mac host no longer gets Apple's `-oso_prefix` linker flag.
- **Registries with a git index** (`registry+<url>` other than crates.io) are cloned and
  read like a sparse index; **`local-registry`** sources work, offline too.
- **`fetch --target`** fetches only what a build for that target uses (repeatable,
  `host` allowed).
- **`login` / `logout`** go through the configured credential providers
  (`cargo:macos-keychain`, `cargo:libsecret`, `cargo:wincred`, plugins); `cargo:wincred`
  is read on Windows.
- **`[target.'cfg(..)']` dependencies** see `-C target-feature` / `-C target-cpu` from
  RUSTFLAGS and the Cargo config, as Cargo evaluates them.

Still different from Cargo (documented): `clean` removes only the files Mitts recorded;
the future-incompatibility report needs `--future-incompat-report`.

No new performance benchmark result is claimed by this release.
