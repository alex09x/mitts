# Mitts 0.5.2

The last two documented differences from Cargo are gone:

- **`mitts clean`** removes the target directory as `cargo clean` does (`--release`: the
  release profile directories). A Cargo build that holds a profile's lock is waited for,
  with Cargo's "Blocking waiting for file lock on build directory". `/`, the home directory
  and a directory containing the project are refused. The selective forms (`-p`,
  `--doc`, `--profile`, `--target`, `--dry-run`) are unchanged.
- **Future-incompatibility report after every build.** Dependencies are compiled with
  rustc's `--json=future-incompat`; after `build`, `check`, `test` and the other build
  commands Mitts names the packages whose code a future Rust will reject and keeps the
  report for `mitts report future-incompatibilities`, from a fresh compile or from the
  cache. `--future-incompat-report` prints the report in full.

The cache key version changes (canonical-v5): the first build after upgrading compiles
everything once.

No new performance benchmark result is claimed by this release.
