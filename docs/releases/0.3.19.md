# Mitts 0.3.19

This release brings the release pipeline and installation checks into the public
source distribution. It does not introduce a new performance claim or benchmark
series.

- Native GitHub archives for macOS/Linux, ARM64/x86-64, with complete checksums.
- Release-only Developer ID signing and Apple notarization for both Mac targets.
- Automatic crates.io publication through a protected GitHub Trusted Publisher.
- Exact-source package verification and immutable, checksum-checked retries.
- Public binary installer, registry Cargo, Git-tag Cargo and clone/path Cargo
  installation checked on all four native targets, including an isolated compile
  with each installed source-built CLI.
- CI checks, native test-store isolation and source-provenance fixes adopted
  since the previous release.

Publication and installation receipts belong to the GitHub Actions release run.
Only completed successful jobs establish that a distribution channel passed.
