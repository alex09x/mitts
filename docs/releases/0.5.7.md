# Mitts 0.5.7

- No progress bar on a dumb terminal or under CI, as Cargo. Mitts drew its spinner and
  hid the cursor on any terminal, so Emacs' `M-x compile` (`TERM=dumb`) and CI logs got
  cursor codes and redrawn lines. Progress now follows Cargo's `term.progress.when`
  (`--config`, `CARGO_TERM_PROGRESS_WHEN` or `.cargo/config.toml`): `always`, `never`, or
  `auto`, which draws unless `TERM=dumb` or `CI`/`TF_BUILD` is set. Cargo rejects an
  unknown value; Mitts takes it as `auto`.
- A failed compile shows the rustc command line only with `-v`, as Cargo. By default
  Mitts printed `Command: ...`, the whole rustc invocation, before the diagnostics. With
  `-v` Mitts still words it `Command: ...` where Cargo says `Caused by: process didn't
  exit successfully`.
- The repository has editor integrations in `editors/`: Vim and Neovim, Emacs, Helix,
  Sublime Text, Zed and a JetBrains plugin (RustRover, IntelliJ IDEA 2026.2 and later),
  tested on Linux, macOS and Windows against the released Mitts. None of them is
  published to a plugin registry by this release.

No new performance benchmark result is claimed by this release.
