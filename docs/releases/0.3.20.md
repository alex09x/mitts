# Mitts 0.3.20

- Runners install the latest stable Mitts and use it for native builds, Clippy,
  formatting and the main test suite.
- The test run emits LLVM coverage with a first-party line-coverage summary and
  downloadable LCOV data; documentation tests are checked separately.
- Release descriptions include human highlights, automatically generated PR
  categories, contributors, commit links and the complete comparison.
- After the owner starts Release in publish mode, signing and crates.io
  publication proceed automatically without separate Environment approvals.
- The supported native matrix is macOS Apple Silicon and Linux ARM64/x86-64.
  The last macOS Intel prebuilt release is 0.3.19; its existing assets remain.

The source-package compiler, exact-source checks, Apple notarization, checksums
and installation acceptance remain release gates. Cargo continues to supply
registry packaging/publication and to test the Cargo installation methods.
No new performance benchmark result is claimed by this release.
