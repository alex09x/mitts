# Mitts 0.5.0

- **Windows (x86-64, MSVC) is supported.** Executables and libraries carry Windows
  names (`.exe`, `.dll`, `.lib`, with import libraries told apart), the store's file
  locks, owned directories, file identities and process checks work there, the
  jobserver is a named semaphore as with Make and Cargo, dep-info and cache-key paths
  are read in either separator, DLL directories go on `PATH`, and a `.pdb` is
  published beside its executable. The whole test suite runs on Windows in CI as a
  required check, beside Linux and macOS.
- Prebuilt `mitts-v0.5.0-x86_64-pc-windows-msvc.tar.gz` (`mitts.exe`, C runtime linked
  in). Install from PowerShell with `irm https://mittsbuild.com/install.ps1 | iex`, or
  with `install.sh` under Git Bash; the GitHub Action works on Windows runners.
- Cargo parity: external `cargo-<name>` subcommands, HTTP proxy routing, `tree
  --features`, fuller `metadata` (dependency kinds, inherited dependencies, patches),
  a resolver that backtracks and honours `rust-version`, workspace member globs in
  every position, and `new`/`init` for Mercurial, Pijul and Fossil.
- Build scripts that write into `OUT_DIR` from a scratch copy (cxx-build, usearch)
  get a writable directory per target directory.

No new performance benchmark result is claimed by this release.
