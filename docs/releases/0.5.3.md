# Mitts 0.5.3

- Every stable option of every Cargo command (773 options in 35 commands, from Cargo's
  own command reference) is checked against Mitts by a test in CI. The check found one
  gap, fixed here: `mitts report` takes Cargo's common options (`-q`, `-v`, `--locked`,
  `--offline`, `--frozen`).

No new performance benchmark result is claimed by this release.
